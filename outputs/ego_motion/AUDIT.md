# Ego-motion mechanism audit

고정된 전역 affine 감산은 새 확인 표본 100개에서 성능 향상을 보이지 않았습니다. 독립 재계산 AUROC는 raw flow/no blob **0.4872**, affine residual/no blob **0.4876**입니다. 이번 감사는 저장된 점수·흐름 성분만 읽었으며 코드·설정·임계값을 변경하거나 영상을 다시 추출하지 않았습니다.

## 정점에서 실제 감산이 작동했는가

새 음성 50개 중 두 방식의 위양성은 **동일한 10개**입니다. affine 방식의 각 점수 정점을 확인하면 **9/10**에서 `insufficient_inliers`로 감산을 보류하고 원래 흐름을 그대로 사용했습니다. 정점과 직전 최대 네 표본, 즉 **가용 최대 5개 표본**이 모두 보류인 클립은 **6/10**입니다. `01321`은 정점까지 1개, `01889`는 3개만 관찰됐습니다. 5개를 모두 관찰했고 모두 보류인 경우는 **4/10**입니다. 이는 사후 설명용 고정 관찰 구간이며 새 검출 규칙에 사용하지 않았습니다.

유일하게 정점에서 fit이 수락된 위양성 `01881`의 radial 성분은 **1.493 → 1.436**, divergence 성분은 **0.0541 → 0.0537**로 소폭 줄었습니다. fit 수락은 전역 affine 모형에 대한 표본 일치도를 뜻하며, 광학 흐름의 정확성이나 물리적인 카메라 운동의 복원을 보증하지 않습니다.

기존에 문제였던 세 음성도 affine 점수 정점까지 최대 최근 5개 표본이 모두 보류였습니다. `01250`은 분석 구간 시작에 가까워 정점까지 표본이 2개이며, 나머지 두 클립은 5개입니다. 해당 정점에서 raw/residual divergence와 radial 성분은 각각 완전히 동일했습니다.

| 기존 음성 ID | raw/no blob 정점 S | affine/no blob 정점 S | 정점까지 최대 5개 중 fit 수락 |
|---|---:|---:|---:|
| 01538 | 15.691 | 16.527 | 0/5 |
| 01510 | 10.798 | 11.438 | 0/5 |
| 01250 | 10.130 | 10.751 | 0/2 |

두 방식의 S는 서로 다른 음성 validation 평균·표준편차로 표준화됩니다. 예를 들어 radial 평균/표준편차는 raw에서 **0.35161/0.36746**, residual에서 **0.31227/0.34743**입니다. 따라서 감산을 보류하여 흐름 성분이 같아도 residual의 표준화 점수가 더 높을 수 있습니다. 위 표의 더 높은 S를 물리적 움직임 증가로 해석하면 안 됩니다. 정점 시각의 이전 EMA 이력도 점수에 영향을 줍니다.

## 범위와 재현 확인

- 새 확인 표본의 클립별 fit 수락 비율 평균은 **58.17%**입니다. 동결된 실행 코드는 양성의 `t < time_of_event`만 사용해 이 비율을 집계하며, 음성은 원래 분석 구간을 사용합니다. 정점 감사도 같은 사건 이전 제한을 적용했습니다.
- 새 양성 50개의 affine 점수 정점은 **24개 수락, 26개 보류**입니다. 보류 사유는 `insufficient_inliers` 16개, `low_motion` 10개입니다.
- 저장된 raw/no blob 시계열 **118개**에서 사건 이후를 제외한 보류 프레임 **5,609개** 모두 raw/residual divergence·radial 성분이 정확히 같습니다.
- 기존 **100개**의 공통 클립 점수·메타데이터는 일치합니다. 기존에 저장됐던 **59개** 프레임 파일도 시각·S·세 성분·임계값 통과 여부가 정확히 같습니다. 최대 절대 차이는 **0**입니다.
- 동결된 코드·설정·기존 산출물·원본 매니페스트·새 표본 주석의 hash 검증이 통과했습니다. 임계값 파일 hash도 calibration freeze 기록과 일치하며 임시 component cache는 삭제됐습니다.

임계값 보정 기록 시각은 **2026-09-13 02:42:03.758 UTC**입니다. 동결된 실행 코드와 로그에서 validation → exploratory → confirmation 순서를 확인했으며 보정 기록이 저장된 confirmation 프레임 파일보다 앞섭니다. 다만 confirmation 추출 시작 UTC 시각을 별도 저장하지 않았으므로 파일 수정 시각만으로 시작 시점을 독립 입증했다고 주장하지 않습니다.

## 해석의 한계

이 결과는 **중앙 영역을 제외해 맞춘 단일 전역 affine 모형과 보류 규칙**의 한계를 보여 줍니다. 모든 자기운동 보정 방식이 무효임을 뜻하지 않습니다. 전진 운동의 깊이별 시차를 복원하지 않았고, 전역 팽창과 화면을 넓게 차지하는 실제 looming을 구분하지 못하는 모형입니다. 위양성 정점의 보류와 성능 부진은 관찰된 연관이며, 수락 조건을 완화하면 성능이 좋아진다는 인과적 증거가 아닙니다.

음성의 전체 프레임은 위양성 클립만 보존되므로, 보존된 시계열의 보류 사유 분포를 모든 음성의 분포로 일반화하지 않았습니다. 이번 결과를 본 뒤 수락 조건·임계값·평가 표본을 조정하지 않았습니다.
